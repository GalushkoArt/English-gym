# English Gym — тренажёр грамматики B1–C1

Веб-тренажёр английской грамматики для русскоязычных. 42 темы от B1 до C1 по мотивам
Raymond Murphy (*English Grammar in Use*, *Advanced Grammar in Use*) и открытых источников
(British Council LearnEnglish, Cambridge Grammar). Статическое SPA, хостится на Cloudflare,
прогресс хранится в браузере.

## Что внутри

- **Темы B1 / B2 / C1.** У каждой — правило с примерами, шпаргалка-формулы, типичные ошибки
  русскоговорящих, 6 флеш-карт и 15 тренировочных вопросов.
- **Карточки с 2, 3 или 4 вариантами.** Три типа заданий: пропуск, выбор верного предложения,
  выбор варианта с тем же смыслом.
- **Подсказки.** Подсказка до ответа (не раскрывает ответ), после ошибки — дополнительная подсказка,
  разбор и перевод предложения. Ошибочный вопрос уходит в конец очереди и возвращается, пока не
  будет решён.
- **Перевод по нажатию.** Любое слово в задании переводится нажатием (словарь `core.json` + глоссарий
  темы). Варианты ответа намеренно не переводятся.
- **Повторение (recap).** Открывается после 5 пройденных тем: случайные вопросы из пройденных тем.
- **Работа над ошибками.** Интервальное повторение (Leitner: сразу → 1 → 3 → 7 → 16 дней).
- **Флеш-карты правил** с тем же интервальным алгоритмом.
- **Блиц · 60 секунд** — два варианта, максимум верных ответов за минуту, личный рекорд.
- **Сертификация B1 / B2 / C1** — 30 вопросов из отдельного экзаменационного банка (в тренировках не
  встречаются), без подсказок, порог 80%. Сертификат можно скачать в PNG или распечатать.
  Он подтверждает результат внутри тренажёра и не является официальным документом.
- **Прогресс:** статус и лучший результат по темам, напоминания «освежить», серия дней, активность,
  экспорт/импорт прогресса в файл, светлая/тёмная тема.
- **Адаптивность:** телефоны, планшеты (вертикально и горизонтально), 16:9 и 21:9. На широких экранах
  тренировка показывает карту сессии слева и шпаргалку справа, главная — три уровня в колонках.
- Клавиатура: `1`–`4` — выбрать, `H` — подсказка, `Enter` — дальше.

## Разработка

Нужен Node.js ≥ 22.18 (валидатор контента запускается через встроенный TypeScript в Node).

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit-тесты + проверка всего контента
npm run validate   # только проверка контента
npm run build      # validate + typecheck + сборка в dist/
```

## Деплой на Cloudflare

**Workers (static assets)** — конфигурация уже в `wrangler.jsonc`:

```bash
npx wrangler login
npm run deploy     # build + wrangler deploy
```

**Pages** — подключите репозиторий в панели Cloudflare Pages:
- Build command: `npm run build`
- Build output directory: `dist`
- Environment variable: `NODE_VERSION=22`

Маршрутизация — через `#/…`, поэтому серверные правила для SPA не нужны. Заголовки кэширования —
в `public/_headers`.

## Контент

- `src/content/topics/<id>.json` — одна тема (схема: `src/lib/types.ts`).
- `src/content/core.json` — общий словарь частотных слов и форм.
- `docs/CONTENT_GUIDE.md` — правила написания тем и вопросов.
- `scripts/validate.ts` — проверка структуры, однозначности формата и покрытия переводом:
  `node scripts/validate.ts --topic <id> --missing` выводит непереведённые слова в виде готового JSON.

Новая тема появляется в приложении автоматически после добавления JSON-файла.
